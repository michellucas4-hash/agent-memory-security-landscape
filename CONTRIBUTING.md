# Como contribuir

Contribuições são bem-vindas para corrigir descrições, atualizar licenças, adicionar fontes oficiais e publicar benchmarks reproduzíveis. Abra issue com URL oficial, commit ou release avaliada, metodologia e limites da evidência. Pull requests devem alterar apenas documentação, dados abertos de fontes públicas ou scripts locais do catálogo.

Não inclua: tokens, chaves, IPs internos, URLs privadas, dumps, logs corporativos, dados pessoais, código copiado de terceiros sem licença aplicável ou afirmações não verificadas de ganhos de desempenho. Não publique código externo neste repositório como se fosse criação própria.

Execute `python3 -m unittest discover -s tests -v` e, quando disponível, seu scanner de segredos antes do PR.

Mantenedores devem revisar qualidade, procedência, licença e riscos antes de aceitar sugestões. Ser citado no catálogo não configura endosso.
