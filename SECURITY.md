# Política de segurança

Este é um repositório editorial de documentação e filtros locais. Os links externos não são auditados continuamente. Se localizar dados privados ou credenciais publicados por engano, **não** replique o conteúdo em issue pública. Utilize o canal privado de vulnerabilidades fornecido pela plataforma GitHub ao proprietário do repositório quando habilitado, ou peça ao mantenedor um canal privado.

Não execute código de origem desconhecida automaticamente, mesmo que esteja relacionado aos projetos catalogados. Não tratamos problemas de segurança de repositórios upstream: reporte-os privadamente aos seus respectivos mantenedores.

A ausência de problemas conhecidos neste catálogo não equivale a certificação de qualquer ferramenta mencionada.
