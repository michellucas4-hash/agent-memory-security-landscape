# Como tornar este catálogo fácil de encontrar no GitHub

O conteúdo já está disponível publicamente. Para que outras pessoas o **encontrem pela busca**, ainda vale preencher os metadados de apresentação do repositório. Eles ficam em **About**, no canto superior direito da página principal. O conteúdo deste documento é uma sugestão pronta para copiar.

## Descrição curta sugerida (About)

> Catálogo open source em português com 45 ferramentas de memória para IA, segurança de agentes, RAG, observabilidade e supply chain. Inclui comparativos, filtros Python e guias de teste.

O GitHub possui limite de tamanho para a descrição; se necessário, use a versão compacta:

> Curadoria OSS em português: memória de IA, segurança de agentes, RAG e LLM observability. 45 projetos, comparativos e filtros Python.

- [x] Fichas que dão crédito aos mantenedores originais.
- [x] Issues e modelos de colaboração.
- [x] Testes em GitHub Actions para o conteúdo deste repositório.
- [ ] Conferir a descrição curta e adicionar *topics* na seção **About** (edição de metadados depende do administrador do repositório).
